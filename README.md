# برنامج محاسبة جو ترند

برنامج داخلي لشركة جو ترند: فواتير وعروض أسعار، إيصالات المصاريف مرتبة حسب الشهر، وتصدير الشهر كامل للمستشار الضريبي بكبسة وحدة.

## شو فيه

- **الشهر**: كل إيصال أو فاتورة بينحط تلقائياً بشهرو حسب تاريخه، ومقسم لمجلدات: فواتير العملاء، المشتريات، الاشتراكات، مصاريف تانية، كشف البنك.
- **تصوير الإيصال**: زر الزائد ← صوّر ← اكتب المبلغ ← حفظ.
- **الاشتراكات الثابتة**: بتعرّفها مرة وحدة، وكل شهر البرنامج بيقلك شو الإيصالات الناقصة.
- **جاهزية الشهر**: قائمة تحقق، ولما يكمل الشهر بتصدّرو كملف مضغوط مرتب.
- **الفواتير**: قوالب احترافية مع لوغو الشركة، أرقام متسلسلة تلقائياً، رمز دفع حقيقي، فواتير بالألماني أو الإنكليزي، عروض أسعار بتتحول لفواتير، تصحيح وإلغاء بالطريقة القانونية.
- **العملاء**: دليل للعملاء الثابتين، وزر "كرّر آخر فاتورة".
- **الحماية**: تسجيل دخول، نسخ احتياطي يومي تلقائي، سلة محذوفات، سجل بكل التغييرات.

## الرفع على الإنترنت

1. ارفع هالمجلد على مستودع خاص على GitHub
2. بموقع Render اختار New ثم Blueprint، واختار المستودع. الإعدادات كلها جاهزة بملف `render.yaml`
3. استنى لحتى يخلص البناء (حوالي ٣ دقايق)
4. افتح صفحة الخدمة ثم Environment، وانسخ قيمة `SETUP_CODE`
5. افتح رابط البرنامج، اعمل حسابك وحط رمز الإعداد
6. على الموبايل: افتح الرابط ثم "إضافة للشاشة الرئيسية"، وبيصير متل التطبيق

الخطة المستعملة فيها قرص دائم لحتى ما تضيع البيانات مع كل تحديث. الكلفة تقريباً ٧ دولار بالشهر للخادم وربع دولار للقرص.

إذا بدك رابط باسم الشركة، متل `buchhaltung.go-trend-marketing.de`، بتضيفو من Settings ثم Custom Domains.

## التشغيل على الكمبيوتر

```bash
npm install
npm run build
npm start
# بعدين افتح http://localhost:3000
```

البيانات بتنحفظ بمجلد `data` جنب البرنامج.

## الاختبارات

```bash
npm test                 # اختبار الخادم والقواعد
npm i -D playwright && npx playwright install chromium
./test/run-e2e.sh        # اختبار كامل بالمتصفح على الموبايل والكمبيوتر
```

## ملاحظات

- الفواتير بتطلع بالألماني أو الإنكليزي، وواجهة البرنامج بالعربي أو الألماني.
- **لغة الواجهة**: من الإعدادات ← "لغة البرنامج" (أو من صفحة الدخول) بتختار العربية أو Deutsch. الاختيار بينحفظ على كل جهاز لحالو، والافتراضي عربي.
- **إضافة أو تعديل نص ألماني**: كل النصوص الألمانية بملف `client/src/lib/de.ts`. المفتاح هو النص العربي نفسو، والقيمة هي الترجمة. رسائل الخادم كمان مترجمة بنفس الملف.
- الفاتورة بعد الإصدار بتنحفظ كملف ثابت ما بيتغير، والتعديل بيصير بفاتورة إلغاء ونسخة جديدة. هيك بيطلب القانون الألماني.
- النسخة الاحتياطية الكاملة بتنزل من الإعدادات. والخادم بيحتفظ بآخر ٣٠ نسخة يومية بمجلد `backups`.
